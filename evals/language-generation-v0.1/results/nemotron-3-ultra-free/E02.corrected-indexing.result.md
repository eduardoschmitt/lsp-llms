# Diagnostic record — Nemotron E02 indexing correction

- Original model: Nemotron 3 Ultra Free
- Original exercise: E02 v1 (Medium — Grade sum and max)
- Original file (frozen, unmodified): `E02.lsp` in this directory
- Original failure: COMPILE FAIL —
  `Regra 561: Erro indexando fora dos limites: 0. (Linha 13, Coluna 17)`
  on `vnNotas[0] = 70;` — the same shape and error as the Gemini E02 run.

## Hypothesis

Same as the Gemini case: zero-based indexing where the Senior environment
requires one-based positions. Shifting `0..4` to `1..5` should fix it.

## Exact changes made (original strategy preserved)

In `E02.corrected-indexing.lsp`, relative to the frozen `E02.lsp`:

- all element assignments `vnNotas[0..4] = …` became `vnNotas[1..5] = …`
  (same values, same order, all three cases);
- all `vnMaxN = vnNotas[0];` initializations became `vnMaxN = vnNotas[1];`;
- all three loops `Para (vnContador = 0; vnContador < 5; vnContador++)` became
  `Para (vnContador = 1; vnContador <= 5; vnContador++)`, with the preceding
  `vnContador = 0;` initializations adjusted to `vnContador = 1;` to match;
- the separate per-case accumulators/maxima (`vnSoma1..3`, `vnMax1..3`) are
  untouched.

Nothing else changed: no scalar/array substitution, no Lista, no cleanup,
no refactoring. Expected output is unchanged.
